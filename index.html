Abstract

We present CSSL, a contrastive semi-supervised method for medical image segmentation. CSSL samples class-wise patches from labelled images and from confident pseudo-labels, separates their embeddings with a supervised contrastive loss with mixed hard negatives, and uses the Silhouette coefficient of the embedding clusters to set the strength of a feature-perturbation consistency loss. Patch embeddings are obtained by masked pooling of the encoder features of the unmasked image, nucleus rims form an additional contrastive class, a memory bank stores past embeddings, and the CSSL losses are added to a weak-to-strong pseudo-labelling recipe. We follow the protocols of the strongest published baselines: Self-Loop on MoNuSeg and DAFNet on CHAOS. On MoNuSeg with 50% labels, CSSL reaches 80.87 ± 0.17 nuclei F1 over three label splits, compared with 79.10 for Self-Loop and 78.73 for the same recipe without CSSL. On CHAOS T2 with 25% labels, CSSL reaches 89.01 Dice, compared with 82.0 for DAFNet and 88.94 for the recipe alone. Ablations show that the contrastive branch, the boundary class and feature-level pooling account for most of the improvement.

Method

Four additions to a weak-to-strong recipe

Class-wise patches

Every 64 × 64 window (stride 32) gives one patch per class with at least 25 pixels, from ground truth on labelled images and from confident pseudo-labels on unlabelled ones. On MoNuSeg, nucleus rims (≤ 2 px from background) are a third class.

Feature-level masking

The encoder sees the whole, unmasked image. The class mask only weights the pooling of the 1/8-resolution features, so context around small nuclei reaches the embedding. CHAOS uses pixel-level masking instead.

Contrastive loss

Supervised contrastive loss (τ = 0.1) on the normalised patch embeddings, with negatives moved towards the anchor by α ~ U(0, 0.4) and, on MoNuSeg, a memory bank of 4096 past embeddings.

Silhouette-adaptive consistency

The Silhouette ω of the patch embeddings sets the noise level λ = (ω̄ + 1)/2 + 0.05 of a feature-perturbation consistency loss on every encoder level, so robustness is demanded only once the classes separate.

ℒ = 1⁄2 ( ℒsup + 1⁄2 ℒs₁ + 1⁄2 ℒs₂ + β ℒCR ) + w(t) ℒCL

β = 0.5 and w = 0.1 (ramped in over 1000 iterations after a 2000-iteration supervised warm-up). Setting β = w = 0 gives the recipe.

Three label splits per dataset, under each baseline's own protocol

Code

From an empty machine to the paper's numbers

One command trains all 28 runs (main results and ablations, about 45 GPU-hours on one 80 GB GPU), checks the runs for leakage, writes the paper's numbers and figures, builds the PDF and prints the result tables. GPU training is not bit-exact, so a rerun lands within run-to-run noise of the reported values.

1. Environment

conda create -y -n cssl python=3.10
conda activate cssl
pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt
python -m pytest -q tests

2. Everything: data, 28 runs, paper

DATA=/data/med STAGES="setup runs paper" nohup bash run_paper.sh > run_paper.log 2>&1 &
tail -f run_paper.log

3. Results at any time

python tools/print_results.py --exp exp
